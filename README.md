# HM Products Sales
## Проект для управления продуктами и категориями интернет-магазина с возможностью загрузки данных из JSON файлов.
## 🚀 Функциональность
### Основные возможности:
- Управление продуктами - создание и хранение информации о товарах
- Управление категориями - организация товаров по категориям
- Наследование продуктов - специализированные классы для разных типов товаров
- Защищенные операции - типобезопасные операции сложения и добавления товаров
- Автоматическая загрузка данных - из JSON файлов
- Автоматический подсчет - количества категорий и товаров
- Полное тестирование - юнит-тесты с проверкой покрытия кода
### Классы:
#### Базовый класс Product - класс товара
- Атрибуты: название, описание, цена, количество
- Методы: инициализация, базовые операции, защищенное сложение
### Классы-наследники Product:
#### Smartphone - класс для смартфонов
##### Дополнительные атрибуты:
- производительность (efficiency)
- модель (model)
- объем встроенной памяти (memory)
- цвет (color)
#### LawnGrass - класс для газонной травы
###### Дополнительные атрибуты:
- страна-производитель (country)
- срок прорастания (germination_period)
- цвет (color)
#### Category - класс категории
- Атрибуты: название, описание, список товаров
- Атрибуты класса: автоматический подсчет категорий и товаров
- Методы: инициализация, получение количества товаров, защищенное добавление продуктов
## 🔒 Защищенные операции:
### Сложение товаров:
- Реализована проверка типов при сложении товаров
- Можно складывать только товары одинаковых классов
- При попытке сложить разные типы товаров вызывается TypeError
### Добавление в категории:
- В категории можно добавлять только объекты класса Product и его наследников
- Проверка реализована с помощью isinstance()
- При попытке добавить неподходящий объект вызывается TypeError
## 🔧 Технические детали
### Зависимости:
- Python 3.13+
- pytest - фреймворк для тестирования
- pytest-cov - проверка покрытия кода
- black, isort - форматирование кода
- flake8 - проверка стиля
- mypy - проверка типов
### Установка:
#### Клонируйте репозиторий:
```
git clone <repository-url>
cd hm-products-sales
```
#### Установите зависимости:
```
poetry install
```
#### Запустите приложение:
```
poetry run python main.py
```
#### Запуск тестов:
Все тесты:
```
poetry run pytest
```
С подробным выводом:
```
poetry run pytest -v
```
С проверкой покрытия кода:
```
poetry run pytest --cov=src --cov-report=term-missing
```
Генерация HTML отчета о покрытии:
```
poetry run pytest --cov=src --cov-report=html
```
## 🛡️ Безопасность типов
### Проект использует строгую проверку типов для обеспечения целостности данных:
- Все операции с товарами проверяют соответствие типов
- Добавление в категории контролируется на уровне наследования
- Математические операции защищены от некорректного использования
