# HM Products Sales
## Проект для управления продуктами и категориями интернет-магазина с возможностью загрузки данных из JSON файлов.
## 🚀 Функциональность
### Основные возможности:
- ✅**Управление продуктами** - создание и хранение информации о товарах
- ✅**Управление категориями** - организация товаров по категориям  
- ✅**Управление заказами** - оформление заказов с расчетом стоимости
- ✅**Наследование продуктов** - специализированные классы для разных типов товаров
- ✅**Защищенные операции** - типобезопасные операции сложения и добавления товаров
- ✅**Автоматическая загрузка данных** - из JSON файлов
- ✅**Автоматический подсчет** - количества категорий и товаров
- ✅**Логирование создания объектов** - автоматическое логирование при создании объектов
- ✅**Абстрактные классы** - единые интерфейсы для продуктов и контейнеров
- ✅**Полное тестирование** - юнит-тесты с проверкой покрытия кода
## 🏗️ Архитектура
### Базовые абстрактные классы:
#### `BaseProduct` - абстрактный базовый класс для всех продуктов
- Определяет общий интерфейс для всех типов продуктов
- Абстрактные методы: `__init__`, `__str__`, `__add__`, `new_product`
- Абстрактные свойства: `name`, `description`, `price`, `quantity`
#### `ProductContainer` - абстрактный базовый класс для контейнеров продуктов
- Определяет общий интерфейс для категорий и заказов
- Абстрактные свойства: `products`, `total_quantity`, `total_cost`
- Абстрактный метод: `__str__`
### Основные классы:
#### `Product` - базовый класс товара
- Наследует от `BaseProduct` и `LogCreationMixin`
- Атрибуты: название, описание, цена, количество
- Методы: инициализация, базовые операции, защищенное сложение
- Особенности: автоматическое логирование создания
#### `Category` - класс категории товаров
- Наследует от `ProductContainer`
- Атрибуты: название, описание, список товаров
- Атрибуты класса: автоматический подсчет категорий и товаров
- Методы: инициализация, получение количества товаров, защищенное добавление продуктов
- Итерация: поддержка протокола итерации по товарам категории
#### `Order` - класс заказа
- Наследует от `ProductContainer` и `LogCreationMixin`
- Атрибуты: товар, количество, автоматический расчет стоимости
- Методы: инициализация, строковое представление
- Особенности: один товар в заказе, автоматическое логирование
### Классы-наследники Product:
#### `Smartphone` - класс для смартфонов
- Дополнительные атрибуты:
  - производительность (efficiency)
  - модель (model)
  - объем встроенной памяти (memory)
  - цвет (color)
#### `LawnGrass` - класс для газонной травы
- Дополнительные атрибуты:
  - страна-производитель (country)
  - срок прорастания (germination_period)
  - цвет (color)
### Вспомогательные классы:
#### `LogCreationMixin` - миксин для логирования создания объектов
- Автоматически логирует создание объектов в консоль
- Форматирует вывод в виде вызова конструктора
- Используется в `Product` и `Order`
#### `CategoryIterator` - итератор для категорий
- Обеспечивает поддержку протокола итерации для категорий
- Позволяет перебирать товары в категории через цикл for
## 🔒 Защищенные операции
### Сложение товаров:
- Реализована проверка типов при сложении товаров
- Можно складывать только товары одинаковых классов
- При попытке сложить разные типы товаров вызывается TypeError
### Добавление в категории:
- В категории можно добавлять только объекты класса Product и его наследников
- Проверка реализована с помощью isinstance() и issubclass()
- При попытке добавить неподходящий объект вызывается TypeError
## 📊 Полиморфизм контейнеров
### Единый интерфейс ProductContainer:
- `Category` и `Order` реализуют общий интерфейс
- Оба класса имеют свойства: `products`, `total_quantity`, `total_cost`
- Возможность обработки разных типов контейнеров через единый интерфейс
## 🔧 Технические детали
### Зависимости:
- ***Python 3.13+***
- ***pytest*** - фреймворк для тестирования
- ***pytest-cov*** - проверка покрытия кода
- ***black, isort*** - форматирование кода
- ***flake8*** - проверка стиля
- ***mypy*** - проверка типов
### Установка:
#### Клонируйте репозиторий:
```
git clone <repository-url>
cd hm-products-sales
```
#### Установите зависимости:
```
poetry install
```
#### Запустите приложение:
```
poetry run python main.py
```
#### Запуск тестов:
Все тесты:
```
poetry run pytest
```
С подробным выводом:
```
poetry run pytest -v
```
С проверкой покрытия кода:
```
poetry run pytest --cov=src --cov-report=term-missing
```
Генерация HTML отчета о покрытии:
```
poetry run pytest --cov=src --cov-report=html
```
## 🛡️ Безопасность типов
### Проект использует строгую проверку типов для обеспечения целостности данных:
- Все операции с товарами проверяют соответствие типов
- Добавление в категории контролируется на уровне наследования
- Математические операции защищены от некорректного использования
- Аннотации типов используются во всех методах и функциях
